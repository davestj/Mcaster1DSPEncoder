Overview

mcaster1-encoder is the Linux CLI + web admin build of the Mcaster1DSPEncoder project. It runs as a standalone binary providing a complete broadcast encoder solution:

HTTP/HTTPS Admin
cpp-httplib v0.18

Embedded web server, sessions, SSL, FastCGI bridge

Audio Engine
PortAudio + libav

Device capture + playlist streaming, MP3/Vorbis/Opus/FLAC

DSP Chain
EQ + AGC + Xfade

10-band parametric EQ, AGC/limiter, equal-power crossfader

Live Streaming
Icecast2 / DNAS

ICY 2.2 extended headers, auto-reconnect, bytes tracking

PHP Web UI
6 PHP pages

Dashboard, encoders, media, playlists, metrics, settings

Logging
Level 1–5

Apache combined format + encoder events + API bodies + stack traces

Build

cd /var/www/mcaster1.com/Mcaster1DSPEncoder
bash src/linux/make_phase4.sh
# Output: build/mcaster1-encoder
ℹ
Build includes -rdynamic for backtrace symbol resolution when log level is set to 5 (DEBUG). Build time ~30–45s on a modern server. Vendor headers (httplib.h, nlohmann/json.hpp) are already in external/include/.

Run as Daemon

nohup ./build/mcaster1-encoder \
  --config src/linux/config/mcaster1_rock_yolo.yaml \
  > /tmp/mc1enc.log 2>&1 & disown $!

echo "Started PID: $!"
tail -f /tmp/mc1enc.log
⚠
Always use disown $! — the shell sends SIGHUP on exit which shuts the encoder down. The nohup ... & disown pattern prevents this.

Kill + Restart

pkill -9 -f 'build/mcaster1-encoder'
sleep 2
nohup ./build/mcaster1-encoder \
  --config src/linux/config/mcaster1_rock_yolo.yaml \
  > /tmp/mc1enc.log 2>&1 & disown $!
⛔
SO_REUSEPORT deadlock: cpp-httplib uses SO_REUSEPORT. If an old instance is alive when you restart, both bind to the same ports. Sessions from the old instance are unknown to the new one → 302 redirects to /login. Always kill all old instances before restarting.

Auto-Bootstrap Bridge

footer.php calls POST /app/api/auth.php {action:"auto_login"} on every page load. This transparently creates a PHP session when C++ auth is valid, using a sessionStorage flag to avoid repeated calls per tab. 

// footer.php — runs once per browser tab
(function(){
  if (sessionStorage.getItem('mc1php_ok')) return;
  mc1Api('POST', '/app/api/auth.php', {action:'auto_login'}).then(function(d){
    if (d && d.ok) sessionStorage.setItem('mc1php_ok', '1');
  });
})();

Known Gotchas

⛔
SO_REUSEPORT — Duplicate Port Binding: cpp-httplib uses SO_REUSEPORT. If an old instance is still running when you restart, both bind successfully to the same ports. Sessions from the old instance are unknown to the new one → silent 302 redirects to /login. Always pkill -9 -f mcaster1-encoder && sleep 2 before restart.
⛔
PHP→C++ Loopback Deadlock: Never curl from PHP to C++ port 8330/8344. C++ thread pool (max 8 threads) gets exhausted: each thread waiting for PHP-FPM, PHP-FPM's curl waiting for C++ to respond. Browser JS must call /api/v1/... directly.
⚠
uopz blocks exit(): The uopz PHP extension intercepts exit() / die() calls. Never use them in PHP. Use return and set the response code + body manually.
⚠
SIGHUP on shell exit: Running nohup ./encoder ... & without disown $! causes the encoder to stop when the shell exits. Always add disown $!.
ℹ
httponly cookie not readable by JS: mc1app_session is httponly — document.cookie won't show it. Use sessionStorage flags in JS to track PHP auth state.
ℹ
DNAS stats XML-in-JSON: GET /api/v1/dnas/stats wraps XML in a JSON body field. Parse with regex: d.body.match(/<listeners>(\d+)<\/listeners>/i)
ℹ
MySQL CLI: Always use mysql --defaults-extra-file=~/.my.cnf — never inline passwords in commands.

Build Instructions

ℹ
Always use build_winqt.ps1 — never use .bat scripts. The ps1 script harvests the MSVC environment from vcvars64.bat, sets QTDIR, runs MSBuild, and conditionally deploys Qt DLLs only when missing. It never deletes existing DLLs, YAML, XML, or config files. 
powershell.exe -NoProfile -ExecutionPolicy Bypass -File win-qt\build_winqt.ps1

Output: win-qt\build\win-qt\Debug\Mcaster1DSPEncoder_Qt.exe

Qt DLLs are deployed automatically by build_winqt.ps1 on first build (when Qt6Cored.dll is absent). Subsequent builds skip windeployqt — no manual DLL copy needed.

Config File Location

⚠
All YAML config files (encoder profiles, DSP effects, global config) are saved next to the running executable. Never save to AppData or any other path. Debug: win-qt\build\win-qt\Debug\ — Release: win-qt\build\win-qt\Release\. Copy YAML files manually when switching between Debug and Release builds.

deploy_release.ps1 performs these steps automatically:

  1. Runs windeployqt.exe --release → copies Qt6Core, Qt6Gui, Qt6Widgets, Qt6Multimedia, Qt6Network, Qt6Pdf, Qt6Svg DLLs plus plugin subdirs: platforms\, multimedia\, imageformats\, styles\, tls\, networkinformation\, iconengines\, generic\
  2. windeployqt also pulls in FFmpeg DLLs: avcodec-61, avformat-61, avutil-59, swresample-5, swscale-8
  3. Copies vcpkg DLLs: portaudio, libmp3lame, ogg, vorbis, vorbisenc, opus, opusenc, FLAC, yaml, libcrypto-3-x64, libssl-3-x64
  4. Copies MSVC CRT DLLs: msvcp140, vcruntime140, vcruntime140_1

Preview Audio Studio (v1.2.0 — preview_audio_studio.h/cpp)

A non-modal floating tool dialog opened via the Preview Audio button in the main window rec bar. Provides three independent monitoring modes:

Bottom Tab Widget

ICY1/ICY2.2 Protocol Reader (icy_stream_reader.h/cpp)

IcyStreamReader is a QObject-based TCP client that opens an independent connection to a stream URL (separate from the QMediaPlayer audio connection), sends Icy-MetaData: 1, parses the full response header block, then tracks audio-byte interleaving to extract metadata blocks (per the ICY protocol spec).

Metadata Block Parsing

After headers, the reader tracks audio bytes vs icy-metaint. At each boundary, it reads a 1-byte length prefix (actual bytes = raw × 16), then the metadata block. The block is parsed with a regex for Key='Value'; pairs per the ICY spec. StreamTitle and StreamUrl are extracted and emitted via the metaUpdated signal.

Encoder Slot State Machine

Each EncoderSlot follows this state machine:

IDLE ──start()──► CONNECTING ──► STREAMING
  ▲                                   │
  └──stop()────────────────────────────┘
  │
SLEEP ──wake()──► IDLE  (auto-triggered after config change in SLEEP state)

When a slot is in SLEEP state and the user edits its config, the slot is automatically woken to IDLE so it can be restarted without manual intervention.

Windows Qt — Known Gotchas

  • Qt macro slots conflict (C4091 / C2059): Qt defines #define slots Q_SLOTS which expands to nothing. Any variable named slots disappears after preprocessing. Never name a variable slots, signals, or emit in Qt code — rename to e.g. slot_entries.
  • Nested type in out-of-line function parameter (C2059 on <): MSVC requires ClassName::NestedType in parameter lists of out-of-class function definitions. std::vector<SlotInfo> → must be std::vector<PreviewAudioStudio::SlotInfo> in the .cpp.
  • DLLs missing after build: build\win-qt\Release\ only contains the .exe and vcpkg DLLs after a build. Qt DLLs and plugin subdirectories are not copied automatically. Always run deploy_release.ps1 — otherwise the app exits silently on launch with a missing DLL error.
  • MOC custom build requires QTDIR: Running MSBuild outside a VS2022 Developer Command Prompt with QTDIR unset causes all MOC steps to fail with "The system cannot find the path specified" (exit code 3). Set QTDIR=C:\Qt\6.9.3\msvc2022_64 and call vcvars64.bat first.
  • gai_strerror Unicode conflict: With UNICODE/_UNICODE defined, gai_strerror maps to gai_strerrorW (returns wchar_t*). Add #define gai_strerror gai_strerrorA in a #ifdef _WIN32 block in any file that uses it.
  • localtime_r not available on Windows: Use localtime_s(&tm, &t) in a #ifdef _WIN32 guard.
  • opusenc.h vcpkg path: vcpkg installs opusenc under opus/opusenc.h — use #include <opus/opusenc.h> not #include <opusenc.h>.
  • IcyStreamReader is a protocol monitor only: It opens a separate TCP connection to the stream URL alongside QMediaPlayer. It reads and discards audio bytes — it does NOT decode audio. Audio decoding is handled entirely by QMediaPlayer + Qt Multimedia (FFmpeg backend).
  • PTT mic sample rate mismatch causes garbled audio: When the mic captures at 48000 Hz and the encoder runs at 44100 Hz (or vice versa), mixing the raw buffers directly produces pitch-shifted/garbled output. Fix: DspPttDuck::process() performs linear interpolation resampling when mic_sample_rate_ != sample_rate_. Pass the capture rate via set_mic_buffer(..., mic_sample_rate).
  • per_encoder_metadata lost when toggling use_global_metadata: Previously, profile_manager.cpp only wrote the per_encoder_metadata: YAML section when use_global_metadata = false. Settings were silently discarded when switching to global mode and back. Fix: always write the section unconditionally.
  • Save-on-exit requires aboutToQuit, not just closeEvent: When the window is minimized to the system tray, closing the window hides it and calls event->ignore(). Subsequent quit via tray menu or Ctrl+Q calls QApplication::quit() which exits the event loop without triggering closeEvent again. Connect QApplication::aboutToQuit to saveSettings() and saveAllEncoderProfiles() to cover all exit paths.
  • MSYS2 bash converts nul → /dev/null: When writing PowerShell scripts via bash heredoc or Python string literals, the Windows null device >nul gets silently translated to >/dev/null. Use the Edit tool on the written file to fix it, or omit the >nul redirect and use only 2>&1.
